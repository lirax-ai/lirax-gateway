# Roadmap

This document records plans. It does not indicate that the listed capabilities have been implemented.

## Current phase: explore governance needs

Track progress in [G-0001](tasks/G-0001-define-first-release.md). Intended participants and expressed needs are documented in [Governance exploration](governance-exploration.md). Explore identity, permissions, temporary approval, audit, and system integration without treating every expressed need as an initial release commitment.

## Later: define the initial release

- [ ] Select a core use case and initial integration scope from the explored needs.
- [ ] Define initial scope, exclusions, and verifiable acceptance criteria.
- [ ] Define the runtime environment, technology stack, and interface constraints; record important tradeoffs.
- [ ] Select an open-source license and add `LICENSE`.

## After scope is defined

- [ ] Implement a core use case that can be verified independently.
- [ ] Provide working quickstart instructions, synthetic examples, and a development guide.
- [ ] Establish automated tests and CI checks appropriate to the implementation.
- [ ] Document configuration, error behavior, and limitations.

Update future milestones based on the initial requirements. Release dates and unconfirmed features are not committed at this stage.
