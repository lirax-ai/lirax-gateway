## Conventions

- Copy the [template](TEMPLATE.md), choose the next available `G-NNNN-topic.md` filename, and add it to this index.
- Use these states: Todo, In progress, Waiting for input, Done, or Cancelled. Maintain state in the task file only, so the index does not duplicate it.
- Record ownership or concurrent editing scopes when assigned. Otherwise write `Unassigned`; an AI assistant is not automatically the owner.
- If scope changes, update acceptance criteria and explain why. Mark a task Done only after its criteria are satisfied and validation is recorded.
- Keep records understandable from this public directory. Include public context, requirements, and evidence; do not require access to private materials or external chats.
