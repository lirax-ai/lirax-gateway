# Lirax Gateway

Lirax Gateway is an open-source project in its initial design stage. Its product scope and first implementation milestone are being defined.

This repository is the public source of truth for the project's code, open questions, and technical decisions. Discussions that start in private research should appear here in a self-contained, sanitized form whenever they affect the project.

## Working on the project

- Use GitHub issues for actionable questions and proposals.
- Record consequential decisions in [`docs/decisions/`](docs/decisions/README.md), including the reasoning and remaining tradeoffs.
- Keep documentation next to the behavior it describes as the implementation takes shape.
- Do not include credentials, personal or customer data, private URLs, or internal identifiers in issues, code, examples, or documentation.

The project is not yet ready to promise a particular API, runtime, or deployment model. Those choices will be documented here as they are made.
