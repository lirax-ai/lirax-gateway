# Lirax Gateway

Lirax Gateway is in its initial design stage. It is intended to become an open-source project, but its scope, first implementation milestone, and license are still being defined.

This repository contains the durable public context for the project. Its [work list](WORK.md) records active questions, [decision records](docs/decisions/README.md) explain lasting choices, and [contributing guide](CONTRIBUTING.md) describes how to work from a checkout. A hosting platform may provide discussions and review, but the project should remain understandable without its issue tracker or API.

## Working on the project

- Keep actionable questions and their next steps in [WORK.md](WORK.md) or a linked repository document. Platform issues are optional discussion channels.
- Record consequential decisions in [`docs/decisions/`](docs/decisions/README.md), including the reasoning and remaining tradeoffs.
- Keep documentation next to the behavior it describes as the implementation takes shape.
- Do not include credentials, personal or customer data, private URLs, or internal identifiers in public discussions, code, examples, or documentation.

The project has not yet selected a runtime or deployment model. These choices will be documented here as they are made.
